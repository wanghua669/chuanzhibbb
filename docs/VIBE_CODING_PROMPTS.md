## 核心迭代 Prompt 链记录

### Iteration 1：顶层架构解耦与“大脑-身体”协议设计
- **人类意图输入 (User Prompt)**：
  > 针对传智杯比赛要求，我的核心方向是“数字人的赛博宠物”，尤其是基于我们提供的个人数据（聊天语料、笔记、日程），去构建成长型、陪伴型的赛博人物分身。让像素数字人不是死板播放动画，而是由大模型作为大脑驱动走动和一系列动作；同时结合前置摄像头做出裸眼 3D 视差玻璃房的感觉，能感知我们的表情，抓取/操作软件前端模块（不破坏后端），还能从空白小屋开始摆放家具或生成礼物，随着好感度提升自己打工赚钱、买礼物给自己或回馈我们。请先设计系统架构，预留大模型 API Key 配置接口。
- **AI 架构响应与约束策略**：
  1. 确立 **“大脑决策（JSON Function Calling）+ 身体执行（2.5D Canvas 状态机）”** 的解耦架构，避免大模型直接参与高频图形渲染。
  2. 将“个人数据驱动的成长型分身”凝练为 **Persona Forge（分身熔炉）** 模块：输入语料/笔记/日程 ➔ 提取六维人格画像 + 口头禅 + 记忆流 ➔ 动态注入 System Prompt。
  3. 设计双模 API 网关：预留标准 OpenAI 兼容接口（支持 DeepSeek/Qwen/GPT 等），同时内置本地启发式引擎确保未填 API Key 时也能完整演示。

### Iteration 2：数据驱动分身构建（Persona Forge）与双模大脑实现
- **人类意图输入 (User Prompt)**：
  > 构建核心数据层与分身养成系统：允许用户导入或编辑日常社交发言、学习笔记、日程安排，实时解析出六维人格画像（共情、外向、理性、创造、自律、幽默）和记忆晶球；设计分身成长等级（Lv.1~Lv.5），并提供可视化的大模型 API Key 配置弹窗（先保留接口供后续填写）。
- **AI 协同实现要点**：
  - 定义强类型数据结构 `PersonaProfile`、`MemoryFragment`、`ScheduleItem`、`BrainActionCommand`。
  - 实现语料特征提取器：自动从用户输入的语料文本中提取高频词汇、情感极性与句式特征，动态映射为六维人格数值与专属口头禅。

### Iteration 3：2.5D 裸眼 3D 视差玻璃房与程序化像素动作引擎
- **人类意图输入 (User Prompt)**：
  > 实现 2.5D 像素箱庭房间与像素小人动作状态机。要求：1. 接入前置摄像头（并提供鼠标/自动演示平滑降级）实现裸眼 3D 视差效果，头往左偏视角往右倾，像屏幕里凹进去一个透明玻璃盒；2. 摆脱外部零散图片资源限制，使用 Canvas 程序化像素矩阵绘制高精度可爱像素分身（支持走动、坐下、敲代码打工、睡觉冒 Zzz、喝可乐、踢 UI 卡片等帧动画）与多层家具。
- **工程难点与 Bug 修复引导**：
  - *问题预判与修正*：若仅依赖摄像头，在无摄像头设备上会导致视差失效。因此采用 `Camera Face Tracking + Mouse Parallax + Breathing Idle Offset` 三重混合坐标解算器，并加入弹簧阻尼滤波（Spring Lerp），消除摄像头抖动导致的画面眩晕感。

### Iteration 4：家园建造、AI 像素造物、好感度打工经济与第四面墙交互
- **人类意图输入 (User Prompt)**：
  > 完成产品闭环：1. 支持从“空白小屋”一键布置像素家具，支持输入文字由 AI 生成 32x32 专属像素物品空投到房间；2. 加入 Heartbeat 自主心跳，闲暇时小人自己去电脑桌打工赚赛博币、去售货机买可乐喝，好感度升级后给主人写观察日记、画像素壁纸、播八音盒音乐；3. 实现小人跨越房间去“踢”右侧逾期日程卡片的前端虚拟物理交互。
- **AI 协同实现要点**：
  - 构建跨组件坐标映射与震动反馈总线（UI Interaction Bridge）：当小人执行 `interact_ui` 动作走到右侧边缘时，触发对应日程卡片或数据模块的 CSS 物理弹跳、火花粒子与状态高亮，严格隔离后端数据修改。

### Iteration 5：视觉与软件形态大重构 —— 内置生图 32-Bit 精绘像素工作流与治愈系桌面软件壳
- **人类意图输入 (User Prompt)**：
  > 你能用内置的生图模型把像素风精致一些，原先纯代码画的方块太潦草了；去看看相关的陪伴桌面项目学习一下，构建自己的美术与开发工作流；还有就是做成桌面软件的形式（不是传统网站滚动页面的形式），前端页面不要暗黑风格，要温馨治愈一点，优化一下并同步仓库。
- **AI 调研与重构决策**：
  1. **标杆项目借鉴与工作流建立**：深度研究 *Spirit City: Lofi Sessions*、*Virtual Cottage*、*Unpacking* 与 *VPet*，编写 [`docs/COZY_PIXEL_WORKFLOW.md`](COZY_PIXEL_WORKFLOW.md)。
  2. **内置生图模型 + 边缘漫水透明抠图管线 (`pixelSpriteEngine.ts`)**：调用内置 AI 生图模型生成 32-Bit 阳光原木画室背景 (`cozy_room_bg.jpg`)、2×2 赛博分身多状态精灵表 (`chibi_characters_sheet.jpg`) 与 2×3 精绘像素家具图集 (`furniture_sheet.jpg`)。针对生成图集带有纯白底色的问题，设计 **Exterior BFS Flood-Fill（外边缘漫水填充透明化算法）**，在完美剔除外部白底的同时，100% 保留人物白卫衣、云朵床与眼白内部的白色像素。
  3. **桌面客户端软件化与暖阳奶油原木 UI**：摒弃暗黑网页风格，全面切换为暖燕麦奶白 (`#FBF6EE`) + 焦糖原木 (`#D4B895`) + 蜜桃暖橙 (`#E07A5F`) 配色；采用 `100vw × 100vh` 无滚动条桌面客户端壳体，内置自定义软件标题栏、伴学番茄钟、左侧角色停靠坞（Dock Rail）、**「完整伴生工作台 / 迷你桌宠挂件模式」** 一键切换，以及独立桌面窗口启动器 (`npm run desktop` / `启动赛博伴生桌面软件.bat`)。
